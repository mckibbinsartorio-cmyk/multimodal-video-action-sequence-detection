# 基于多模态大模型的视频动作序列检测

> **项目状态：进行中（私有仓库）**  
> 本仓库用于记录研究过程、实验配置与阶段性结果；在项目结题、完成数据与代码脱敏及复现整理后公开。

## 1. 项目简介

视频动作理解不仅需要识别单帧画面中的动作类别，还需要建模动作在时间维度上的起止、顺序与上下文关系。传统视频理解方法在长视频时序建模、跨片段语义关联及自然语言交互方面仍存在局限。

本项目拟探索多模态大模型在**视频动作序列检测**任务中的应用：以视频及其时序信息为核心输入，结合视觉与语言模态，输出具有时间顺序的动作事件序列，并对动作类别、时间区间和语义描述进行结构化表示。

## 2. 研究问题

本项目聚焦以下问题：

1. 如何将长视频有效切分、采样并输入多模态大模型，同时保留关键时序信息？
2. 如何让模型从视频中识别多个连续或重叠的动作，并生成有序的动作序列？
3. 如何设计提示词、结构化输出或后处理策略，提升动作边界与类别预测的稳定性？
4. 如何在公开数据集或自建场景中，定量评估方法在动作识别、时序定位与序列一致性上的表现？

## 3. 方法概览

整体流程暂定如下：

```text
原始视频
  -> 视频解码与帧/片段采样
  -> 时序片段表示与多模态提示构建
  -> 多模态大模型推理或微调
  -> 结构化动作事件输出
  -> 时序约束与后处理
  -> 动作序列检测结果
```

后续将在此处补充方法框架图、模型细节及各模块的输入输出定义。

## 5. 实验设计（持续更新）

### 5.1 任务定义

- **输入**：视频样本，可包含帧序列、片段特征、字幕或文本提示。
- **输出**：按时间排序的动作事件列表，格式示例：

```json
[
  {
    "start_time": 0.0,
    "end_time": 2.4,
    "action": "动作类别或自然语言描述",
    "confidence": 0.0
  }
]
```

### 5.2 评价指标

计划根据最终任务与数据集选择以下指标：

- 动作分类准确率 / F1；
- 时序定位 mAP（不同 IoU 阈值）；
- 动作序列编辑距离或序列一致性指标；
- 推理耗时与显存占用。

### 5.3 实验记录规范

每次有效实验建议在 `docs/experiment-log.md` 记录：日期、分支或提交编号、数据版本、模型与参数、结果、现象和下一步假设。负结果也保留，便于后续写实验分析与避免重复尝试。
